# Multicast Design System

Sistema autoral do Multicast derivado da fusao entre a disciplina estrutural da Asana e a composabilidade do Untitled UI, recalibrado para uma plataforma de streaming social com atmosfera cinematografica.

## Objetivo

Construir uma base visual que sustente:

- descoberta de conteudo
- criacao e gestao de salas sincronizadas
- chat, presenca e controle compartilhado
- fluxos densos de produto sem perder apelo emocional

O sistema nao replica Asana nem Untitled UI. Ele absorve o melhor dos dois e muda o eixo visual para entretenimento compartilhado.
