# Composed Streaming Components

## Componentes de dominio inicial

### MediaCard

Uso:

- descoberta de filmes, series, episodios ou trailers

### RoomCard

Uso:

- listar salas disponiveis
- destacar status, numero de participantes e politica de acesso

### ParticipantStrip

Uso:

- mostrar presenca social em sala, lobby ou convite

### EmptyState

Uso:

- estados sem conteudo com CTA claro

### StatCard

Uso:

- metricas de uso, audiencia, rooms criadas, watch time
