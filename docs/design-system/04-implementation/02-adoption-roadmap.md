# Adoption Roadmap

## Proximo ciclo recomendado

1. criar showcases internos ou stories do design system
2. aplicar a nova base `shadcn/ui` em fluxos reais: auth, lobby, room, billing
3. implementar command menu, table, chat bubble, queue item e playback toolbar
4. validar contraste e refinamento mobile em contexto real
5. expandir compostos especificos de streaming sem quebrar a fundacao compartilhada

## Criterio de pronto

- tokens estabilizados
- fundacao `shadcn/ui` consolidada para primitives interativos
- componentes reutilizados em telas reais
- comportamento consistente em dark e light
- documentacao atualizada quando novos compostos surgirem
