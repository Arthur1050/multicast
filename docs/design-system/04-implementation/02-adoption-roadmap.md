# Adoption Roadmap

## Proximo ciclo recomendado

1. criar showcases internos ou stories do design system
2. implementar dropdown, select, modal e tooltip
3. implementar chat bubble, queue item e playback toolbar
4. aplicar o sistema em fluxos reais: auth, lobby, room, billing
5. validar contraste e refinamento mobile em contexto real

## Critério de pronto

- tokens estabilizados
- componentes reutilizados em telas reais
- comportamento consistente em dark e light
- documentacao atualizada quando novos compostos surgirem
