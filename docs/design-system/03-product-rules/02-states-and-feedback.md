# States And Feedback

## Estados obrigatorios

- default
- hover
- focus-visible
- active
- selected
- disabled
- loading
- success
- warning
- error
- live
- reconnecting

## Regras

- estados de rede precisam aparecer antes de erros genicos
- loading de player e loading de dados nao usam a mesma linguagem
- feedback destrutivo pede confirmacao textual
- reconexao deve parecer temporaria, nao fatal
