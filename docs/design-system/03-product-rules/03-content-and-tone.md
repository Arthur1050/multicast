# Content And Tone

## Tom de voz visual

- sofisticado
- acolhedor
- direto
- sem jargao tecnico desnecessario

## Regras de copy para UI

- CTAs curtos
- erros especificos
- mensagens de sala com foco em companhia e sincronizacao
- textos de permissao devem ser inequívocos

## Anti-padroes

- labels vagas como "Continuar" sem contexto
- uso excessivo de linguagem gamer ou meme
- microcopy dramatica para estados comuns
